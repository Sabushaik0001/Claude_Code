# 🧠 What is Kiro?

**Kiro** is an AI-driven development platform designed to help developers build, automate, and manage applications efficiently using intelligent agents.

✨ With Kiro, you can:
- Generate code instantly  
- Structure development using specs  
- Automate workflows  
- Move from idea to production faster  

---

# 🏢 Provider

**Kiro is provided by AWS (Amazon Web Services)**  

- Integrated with AWS ecosystem  
- Supports login via AWS Builder ID / GitHub  
- Built for cloud-native development  

---

# 🖥️ Kiro IDE

## Overview
Kiro IDE is a visual development environment for structured AI-driven development.

## Features
- Agent Specs (Requirements, Design, Tasks)  
- Agent Steering (control AI behavior via .md files)  
- Agent Hooks (automation triggers)  
- VibeCode (rapid UI prototyping)  

## Installation
Download: https://kiro.dev/downloads/  
Docs: https://kiro.dev/docs/getting-started/installation/

# 💻 Kiro CLI

## Overview
Kiro CLI is a terminal-based interface for automation and AI workflows.

## Installation (Ubuntu)
```bash
curl -fsSL https://cli.kiro.dev/install | bash
```

## Usage
```bash
kiro-cli
kiro-cli login
```

Docs: https://kiro.dev/docs/cli/
